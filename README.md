# Godbound — русская система для Foundry VTT

Неофициальная русскоязычная система для настольной ролевой игры **Godbound** (Kevin Crawford, Sine Nomine Publishing) в [Foundry Virtual Tabletop](https://foundryvtt.com/).

Godbound — игра о смертных, получивших искру божественной силы. Игроки берут на себя роли новорождённых богов, меняющих раздробленный мир силой Слов Творения.

## Возможности

- **Листы персонажей** — Годбаунды с атрибутами, фактами, Словами, Дарами, очками Силы (Effort), Влиянием и Владениями.
- **НИП и толпы (Mobs)** — отдельные типы актёров для противников и массовых сражений, с автоматическим расчётом размеров токенов.
- **Слова и Дары** — компендиум с описаниями на русском языке, включая активацию Даров прямо с листа персонажа.
- **Теургия и Низшая магия** — компендиумы заклинаний с поддержкой уровней и трат.
- **Артефакты** — предметы с привязанными Дарами и стоимостью Доминиона.
- **Фракции** — листы фракций и действия фракций для стратегического слоя игры.
- **Броски** — проверки атрибутов, атаки, урон с таблицей божественного урона, испытания (saving throws) — всё в чат с интерактивными карточками.
- **Компендиумы**: Слова и Дары, Теургия, Низшая магия, враги, примеры артефактов и фракций, а также материалы сеттинга «Секреты Аркема».

## Установка

### Через манифест (рекомендуется)

1. В Foundry VTT откройте **Game Systems → Install System**.
2. В поле **Manifest URL** вставьте:

   ```
   https://raw.githubusercontent.com/drulmir/godbound-ru/main/system.json
   ```

3. Нажмите **Install**.

### Вручную

Скачайте архив репозитория и распакуйте его в папку `Data/systems/godbound` вашей установки Foundry VTT.

## Совместимость

- Foundry VTT **v13–v14**.
- Основной язык интерфейса — русский (работает и при английской локали клиента).
